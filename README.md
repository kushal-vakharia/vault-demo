# Vault UI Demo

A minimal file management interface built with Next.js with MUI, featuring virtualized lists and simulated file uploads.

## Features

- Simulated file upload with loading/error states
- Virtualized file list (5+ items)
- Real-time search and filtering
- Responsive design
- TypeScript for type safety

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Run the development server:

```bash
npm run dev
```
